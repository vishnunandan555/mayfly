---
title: "mayfly audit"
description: Inspect access records and cryptographically verify the SHA-256 tamper-evident log chain.
icon: FileCheck
---

## Synopsis

```bash
mayfly audit [command] [--limit 50] [--verify]
```

---

## Subcommands

### `mayfly audit log`
Display the chronological event history of secret access, injections, and modifications:

```bash
mayfly audit log --limit 20
```

### `mayfly audit verify`
Traverse the entire audit log file (`~/.mayfly/audit.log`) and verify the cryptographic continuity of the SHA-256 hash chain:

```bash
mayfly audit verify
```

Output:
```
[AUDIT VERIFICATION]
  Total Events Scanned: 48
  Genesis Checkpoint:   PASSED
  Chain Continuity:     PASSED (48/48 blocks valid)
  Tamper Detection:     CLEAN (No alterations detected)
```

If any entry was modified or removed out of sequence:

```
[ALERT] INTEGRITY VIOLATION DETECTED AT SEQUENCE #14
  Expected Previous Hash: 7a356b27...
  Actual Previous Hash:   9f81a2e3...
  Status: LOG HAS BEEN COMPROMISED OR ALTERED
```
